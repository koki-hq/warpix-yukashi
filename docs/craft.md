# 店づくりの決まり

## いちばん大事なこと

- この店は**開きっぱなしにしてもらう居場所**。人はその間、別の作業をしている
- 邪魔はしない。でも、ふと目をやると何かが起きていて、ちょっといい気分になる
- ゲームっぽくしない。点数、達成、急かす表示は置かない
- 動画との違いは、**店があなたを覚えていて、あなたの時間と一緒に流れていること**
- 迷ったら、静かなほう、ゆっくりなほうを選ぶ

## 絵

- 画面は **320×180 ドット**。整数倍に拡大して、ぼかさずに表示する
- 色は `src/palette.js` の29色だけ。足すときは、パレットごとバージョンを上げる
- **引きの絵**。主役はインテリアと空気。住人は小さく描く
- 小物は `src/sprites.js` に、1文字＝1ドットの文字列で描く。左右対称のものは半分だけ描いて鏡写しにする
- 本の背表紙のように数が多いものは、決まった種（シード）の乱数で並べる。開くたびに配置が変わらないように

## 光

- 光はなめらかなグラデーションにしない。段階に丸めて、境目は網点（ディザ）でぼかす
- 光は二種類。部屋全体の色（ambient）と、点の光（ランプ、窓）
- 昼と夕方は、窓から床に光が差しこむ
- 窓の外の空と、ランプの光源そのものは、暗くしない

## 動き

- 動きはカクカクでいい。1秒に8コマくらいが基本
- 何かが起きる間隔は長めに。数十秒から数分に一回
- できごとは本当の時刻から決める（`happening()`）。乱数を使わないので、いつ開いても続きから始まり、同じ時刻なら誰が見ても同じことが起きている
- 1コマの描き方：窓の外 → 店の中（動かない部分。一度だけ描いてとっておく）→ 住人と時計の針 → 光 → 灯りと湯気

## 軽さ

- 開きっぱなしにされるので、1コマは数ミリ秒におさえる。`node tools/perf.mjs` で測れる（0.3.0 で約3ミリ秒）
- 光の明るさは時間帯ごとに表にしてとっておき、毎コマはそれをかけるだけ

## 音

- BGM は 8bit の音色で、Web Audio で合成する（音声ファイルを使わない）。`src/music.js`
- 音はドアを開けた（クリックした）あとにだけ鳴らす
- **作業のじゃまをしない**がいちばん。0.6 の夜の曲が「ちょっと不気味」と言われた反省から：
  - 短調にしない。夜らしさはテンポと音の暗さで出す
  - 和音とメロディの音階をそろえる。メロディは和音の音か、調の音だけ。書いたら一音ずつ和音と照らし合わせる
  - メロディは手で作曲する（その場で紡ぐと、ときどき変なところへ行く）。音は少なめ、休む周をはさむ
  - 細い矩形波は小さく、こだまは薄く
- メロディは `music.js` の楽譜の文字列で書く。1小節に8つ（8分音符）、音名で鳴らし、「-」でのばし、「.」で休む
- 音量は作業のじゃまにならない大きさ。`node tools/listen.mjs <曲> <秒>` で wav に書き出して、音割れ・無音がないかを確かめる（0.4.0 で、ピーク約0.19）
- タブが裏にあっても音楽は止めない（作業のおとも）。裏ではタイマーが遅くなるので、音を多めに先まで予約する

## 技術

- 素の HTML / CSS / JavaScript。ビルドなし、本番のライブラリなし
- タブが裏にあるときは描画を止めて、時間の経過だけ計算する
- 確認用の道具（Playwright）は開発のときだけ使う。`npm run shot` で画面を撮って、絵を変えたら必ず目で確かめる
- URL に `?time=18:30` をつけると、その時刻の店を見られる
