# アイデアの引き出し

やるかどうか未定のもの。やったら CHANGELOG に書いて、ここでは「済」をつける。

## 入店まで

- （済 0.6.0）ドアをクリックして入店。ドアの鈴と「いらっしゃいませ」。BGM が流れはじめる
- （済 0.6.0）一人称で角の席まで歩いて、座る
- （済 0.6.0）いつの間にか注文が決まっている（お客さんは選ばない）
- 店の表の窓に、中の人影や棚がもっと見えるように
- 雨の日、霧の朝を店の表と窓の外に描く

## 時間とともに

- （済 0.6.0）タブのアイコンのコーヒーが少しずつ減っていく
- （済 0.6.0）飲み終わると、黙っておかわり。数字のないタイマー
- （済 0.6.0）コーヒーが冷めると湯気が消える
- 甘いもの：昼すぎはプリン、朝はシナモントースト。カップの横に小皿
- （済 0.3.0）おくのさんの一日（characters.md）に合わせて、することが変わる
- （済 0.3.0）深夜はおくのさんがうたた寝
- （済 0.5.0）ゆかしも一日の中で居場所を変える（characters.md）
- （済 0.5.0）しばらくいると、ゆかしがテーブルに来て、ゆっくりまばたきして、すりすり
- 窓辺のゆかしが、ごくまれに振り返ってこちらを見る
- ゆかしが居場所を移るところを、ごくまれに見られる（歩いている姿）
- 暦（二十四節気）で、窓の外の木と、カウンターの小物が入れ替わる
- 霧の朝、雨の日。天気は店の中の暦で決める（お客さんの位置は使わない）
- 坂の下を路面電車が通る音が、ときどき遠くで

## 覚えていてくれる

- （済 0.6.0）タブに戻ると、おくのさんが「おかえりなさい」と会釈
- （済 0.6.0）何度か来ると「いつもの」が出てくる
- **植物が、はじめて来た日から本物の日数で少しずつ育つ**。ポトスが床に届くのは何か月か先
- ゆかしは、覚えたお客さんにだけすり寄る
- 帰るときに「お会計」。滞在時間、杯数、ゆかしが来た回数が書かれたレシート

## 触ると何かが起きる

- （済 0.3.0）本棚のリボンの帳面：開くとスケッチ帳。店を描いている誰かの作業ノート（world.md）。本番の店では別のタブで開く
- おくのさん：ひとりごと（data/hitorigoto.txt）
- 本棚の本：一冊抜くと、知らない本の書き出し一文が読める
- 空想地図：クリックすると、存在しない町の地名がひとつ読める
- ジュークボックス：曲が変わる
- 窓：開けると外の音が少し入る
- 湯気：ごくまれに、何かの形に見える
