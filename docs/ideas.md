# アイデアの引き出し

やるかどうか未定のもの。やったら CHANGELOG に書いて、ここでは「済」をつける。

## 入店まで

- ドアをクリックして入店。ドアの鈴と「いらっしゃいませ」。BGM が流れはじめる
- 一人称で角の席まで歩いて、座る
- おくのさんが来て、いつの間にか注文が決まっている（お客さんは選ばない）

## 時間とともに

- タブのアイコンのコーヒーが少しずつ減っていく
- 一定時間ごとに、おくのさんが黙っておかわりを注いでくれる。数字のないタイマー
- おくのさんの一日（characters.md）に合わせて、することが変わる
- 深夜はランプひとつ。おくのさんはうたた寝
- 暦（二十四節気）で、窓の外の木と、カウンターの小物が入れ替わる
- 霧の朝、雨の日。天気は店の中の暦で決める（お客さんの位置は使わない）
- 坂の下を路面電車が通る音が、ときどき遠くで

## 覚えていてくれる

- タブに戻ると、おくのさんが「おかえりなさい」と会釈
- 何度か来ると「いつもの」が出てくる
- **植物が、はじめて来た日から本物の日数で少しずつ育つ**。ポトスが床に届くのは何か月か先
- ゆかしは、覚えたお客さんにだけすり寄る
- 帰るときに「お会計」。滞在時間、杯数、ゆかしが来た回数が書かれたレシート

## 触ると何かが起きる

- おくのさん：ひとりごと（data/hitorigoto.txt）
- 本棚の本：一冊抜くと、知らない本の書き出し一文が読める
- 空想地図：クリックすると、存在しない町の地名がひとつ読める
- ジュークボックス：曲が変わる
- 窓：開けると外の音が少し入る
- 湯気：ごくまれに、何かの形に見える

- らくがき帳。ほかのお客さんが残した一言を、めくって読める
