# 世界観

## 店の名前

「ゆかし」は古い言葉で、**なんとなく心がひかれる、見てみたい、知りたい、なつかしい**という気持ちのこと。

店の名前は猫からとった。猫の名前は、おくのさんが窓の外をじっと見る子猫を見て「何がそんなにゆかしいんだい」と言ったことからついた。だから順番は、言葉 → 猫 → 店。

## 店のある町

**月見坂（つきみざか）**。海の見えない港町の、長い坂の途中にある。

- 坂の下には路面電車が走っている。店のいちばん近くの停留所は「月見坂中腹」。終点のひとつ手前
- 坂の上には、いつ行っても閉まっている天文台がある
- 町の人は、夜に坂の上から下を見ると、町の灯りが海のように見えると言う。だから「海の見えない港町」
- 霧が出る朝が多い。霧の朝は、店の窓が白い紙みたいになる

店は、古い二階建ての洋館の一階。二階はおくのさんの住まいと、本の倉庫。

## 店に流れる時間

- 店の時計は、お客さんの時計とぴったり同じ時刻をさす。おくのさんは「お客さんが持ってきた時間で営業している」と言う
- 灯りがついているあいだは開いている。閉店時間は決まっていない
- 夜が深くなると、おくのさんはカウンターでうたた寝をする。それでも店は開いている
- 季節は町の暦どおりにめぐる。窓の外の木、窓辺の植物、カウンターの小物が少しずつ変わる
- 天気も町の暦が決めている。霧は朝にだけ来て、雨は三時間ほど降って、やむ。お客さんの町の天気とは関係がない。おくのさんは「この坂には、坂の天気があるんです」と言う

## 空想の境目

この店には、ほんの少しだけ不思議がまぎれこんでいる。でも、はっきり魔法だと分かることは起きない。

- 起きるのは「気のせいかもしれない」くらいのこと。本のページが増えた気がする、湯気が一瞬だけ何かの形に見えた、など
- おくのさんはそれを不思議がらずに、ひとりごとで話す
- 種明かしはしない

## 本棚の帳面

本棚の二段目に、リボンのはみ出た帳面が一冊まぎれている。背には何も書いていない。

開くと、この店そのもののスケッチ帳になっている。パレット、時間帯ごとの光、住人の下描き。誰かがこの店を描いている途中の作業ノート。

おくのさんはこの帳面のことを知っているのか、知らないのか。聞かれたら「ああ、それはずっとそこにあるんですよ」とだけ言う。
