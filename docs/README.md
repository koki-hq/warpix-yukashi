# 喫茶ゆかし 設定資料

店の世界観、住人、間取り、店づくりの決まり。ソースと同じリポジトリに置いているので、バージョンごとに「そのときの店」と「そのときの設定」がそろって残る。

| 資料 | 中身 |
|---|---|
| [world.md](world.md) | 世界観。店のある町、店の名前の由来、店に流れる時間 |
| [characters.md](characters.md) | おくのさんとゆかし。ほか、店に出入りするもの |
| [shop.md](shop.md) | 間取り、インテリア、植物、メニュー、音 |
| [craft.md](craft.md) | 店づくりの決まり。絵、光、音、技術 |
| [ideas.md](ideas.md) | アイデアの引き出し。やるかどうか未定のもの |
| [versions.md](versions.md) | バージョンの付け方と、前の店に戻る方法 |
| [../CHANGELOG.md](../CHANGELOG.md) | 店の歩み。バージョンごとに何が変わったか |

設定は空想のメモなので、つくりながら変わっていい。変えたら、そのバージョンの CHANGELOG に一行残す。
