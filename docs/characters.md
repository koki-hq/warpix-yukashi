# 住人

絵の上では小さく、「なんかいるんだなあ」くらい。主役は店の空間で、住人はその空気の一部。

## おくの さん（奥野 冬彦）

- 店主。白髪、六十代の終わりくらい
- 白シャツに、日によって黒か焦げ茶のベスト。袖は少しまくっている
- 若いころは**地図をつくる仕事**をしていた。町を歩いて測って、紙に写す
- いまは、ひまな時間に**存在しない町の地図**を描いている。手帳の名前は「空想地図帳」。店の壁に一枚だけ貼ってある
- 好きなもの：読書、コーヒー、猫、霧の朝、古い時刻表
- 苦手なもの：急ぐこと。電話（店に電話はある。鳴ったことはほとんどない）
- しゃべり方：ていねいで、ゆっくり。「〜なんです」「〜でしょうね」「〜かもしれませんよ」
- お客さんに話しかけることはあまりない。ひとりごとが、たまたま聞こえる距離にいる
- 本を読むときだけ、丸い眼鏡をかける

### おくのさんの一日

| 時間 | していること |
|---|---|
| 朝 | 窓を開けて、植物に水をやる。豆を挽く |
| 昼 | カウンターで本を読む。ときどきカップを磨く |
| 夕方 | 窓の外を見ている。ゆかしと同じ方向を見ていることが多い |
| 夜 | ランプの下で空想地図帳を描く |
| 深夜 | うたた寝 |

## ゆかし

- 看板猫。三毛猫、メス、七歳くらい
- 七年前の雨の日に、店の軒下で雨宿りしていた。そのまま住んだ
- 好きな場所：窓ぎわの椅子、床の日だまり、窓辺、本棚の三段目、コーヒー豆の麻袋の上
- 苦手なもの：ミルで豆を挽く音（耳を少し伏せる。逃げはしない）
- 夕方になると窓の外を見る。何を見ているのかは、おくのさんにも分からない
- しばらくいるお客さんのところには、そっと来る。テーブルに上がって、こちらを見て、ゆっくりまばたきをする（猫の「好き」の合図）。頭をすりすりして、また自分の場所に帰る

### ゆかしの一日

| 時間 | 居場所 |
|---|---|
| 朝 | 窓ぎわの椅子で丸くなる（朝いちばんに日が当たる） |
| 昼 | 床に落ちた窓の日だまりで眠る |
| 夕方 | 窓辺に座って、外を見ている |
| 夜〜深夜 | 本棚の三段目で眠る |
| しばらくいると | お客さんのテーブルに来る（15分いたらはじめて。そのあとは20分ごとに1分ほど） |

## 店に出入りするもの

- **郵便屋さん**：ときどき窓の外を自転車で通る。店には寄らない
- **路面電車**：坂の下を通る音が、ときどき遠くで聞こえる
- **雀**：朝、窓の外の手すりにとまる。ゆかしが見ている
