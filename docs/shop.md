# 店の中

## お客さんの席

**店のいちばん奥、角のテーブル席**。ここから店全体が見わたせる。
目の前には自分のテーブルの端と、自分のカップ。その向こうに店が広がっている。

画面は、この席から見た景色。

## 見えているもの（左から）

| 場所 | もの |
|---|---|
| 左の壁 | 大きな格子窓。外には坂の町と、通りの向かいの木。窓辺に小さな鉢がならぶ |
| 窓のそば | 二人がけの小さなテーブル。だいたい誰も座っていない |
| 中央の壁 | 壁の時計、おくのさんの空想地図 |
| 中央奥 | カウンター。後ろの棚にカップ、豆の瓶、サイフォン。カウンターの端に古いジュークボックス |
| 右 | 天井までの本棚。下の段には麻袋 |
| 右手前 | 大きなモンステラ |
| 天井 | 太い梁、ペンダントランプ、吊り下げたポトス |
| 床 | 古い板張り。窓の下に色あせた絨毯 |

## 植物

おくのさんは植物に名前をつけない。でも、ひとつずつ呼び方がある。

- **モンステラ**：店でいちばん大きい。おくのさんは「森の入口」と呼ぶ
- **ポトス**：梁から吊るしてある。少しずつ伸びて、床に届くのを待っている
- **窓辺のサボテンたち**：三つ。冬になると一つだけ花が咲く
- **カウンターのミント**：おくのさんがたまにちぎって匂いをかぐ
- **シダ**：本棚のいちばん上。どうやって水をやっているのかは謎

## メニュー

| 品 | ひとこと |
|---|---|
| **ゆかしブレンド** | 店の「いつもの」。深煎りで、少しだけ甘い香り |
| 月見ブレンド | 夜だけ。浅煎りで、明るい酸味 |
| 霧の朝のミルクコーヒー | 霧の出た朝だけ |
| 固めのプリン | カラメルが苦い |
| シナモントースト | 厚切り |
| レモンケーキ | おくのさんが「夏の味がする冬のお菓子」と言う |

注文は、お客さんが選ばなくても決まる。おくのさんが顔を見て決める。

| とき | 出てくるもの | おくのさんのことば |
|---|---|---|
| はじめて | ゆかしブレンド | 「はじめてでしたら、ゆかしブレンドを。……実はもう、淹れてあるんです。」 |
| 3回目から | ゆかしブレンド | 「いつもので、よろしいですね。」 |
| 夜（19時〜5時） | 月見ブレンド | 「夜ですから、月見ブレンドにしましょうか。」 |
| 霧の朝 | 霧の朝のミルクコーヒー | 「霧の朝ですから、ミルクコーヒーにしましょう。」 |

霧の朝は、日付で決まる（三日に一日くらい）。同じ日なら、誰が来ても霧。

コーヒーは25分ほどで飲み終わる。空になって2分すると、おくのさんが黙っておかわりを置いていく。

## 店の表

坂の途中の、古い二階建ての洋館。一階が店で、二階がおくのさんの住まい。

- しっくいの壁に木の梁。二階の窓辺に花箱
- 葡萄酒色と生成りのしまの日よけ
- 左右に大きな格子窓。夕方からは店の灯りがもれる
- 真ん中にガラスの入った木のドア。上に小さな鈴
- ドアの右に、カップの絵の吊り看板（文字はない）
- ドアの左に大きなシダの鉢、右に小さな花の鉢。石段が二段
- 右の端に街灯。夜に灯る

## 音

- BGM は、カウンター端の古いジュークボックスから流れている。おくのさんが直したもので、どんな曲もどこか 8bit の音になる
- 中には10枚のレコードが入っている。チップチューン、ジャズ、ローファイ、環境音楽。どれも、おくのさんが「本を読むじゃまにならない曲」として選んだもの
- ふだんは「おまかせ」で、時間帯に合う曲を機械が勝手に選ぶ。おくのさんは「機械のほうの気分でしょう」と言う
- 曲名の一覧は README の「9. 音楽と音」
- 環境の音：時計の秒針、カップを置く音、ときどき遠くの路面電車
