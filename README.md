# 喫茶ゆかし 説明書

**版 0.10.0（プレオープン）**

坂の途中にある、ピクセルアートの喫茶店です。ドアを開けて入店し、角の席に座ったら、あとは何もしなくてかまいません。開きっぱなしにして、ほかの作業をしていてください。ふと目をやると、店では何かが起きています。

[WARPIX製作所](https://koki-hq.github.io/warpix/) の作品です。

- **店**：https://koki-hq.github.io/warpix-yukashi/
- **スケッチ帳**（店づくりの作業台）：https://koki-hq.github.io/warpix-yukashi/sketchbook.html
- **店の歩み**（版ごとの変更）：[CHANGELOG.md](CHANGELOG.md)、[リリース一覧](https://github.com/koki-hq/warpix-yukashi/releases)
- **設定資料**（世界観、住人、店の中）：[docs/](docs/README.md)

---

## 1. 入店のしかた

1. 店を開くと、**店の表**が見えます。坂の途中の古い洋館の一階で、しまの日よけ、左右の格子窓、真ん中にドアがあります。左の窓からはカウンターとおくのさん、右の窓からは丸テーブルと本棚が見えます（昼はガラスに空が映りこみ、夕方からは灯りがもれます）
2. **ドアをクリック**します。キーボードなら、画面をクリックしてから Enter かスペースでも開きます
3. ドアの鈴が鳴り、ドアが開いて、おくのさんの「いらっしゃいませ」が聞こえます
4. ドアの向こうへ入り、カウンターの前から奥の角の席まで、一人称で歩いて座ります（およそ7秒。飛ばすことはできません）
5. ドアを開けてすぐに、ジュークボックスが鳴りはじめます（前回、音楽を止めて帰ったときは鳴りません）
6. 座って少しすると、おくのさんが注文を決め、さらに数秒すると、カップを置く音がしてテーブルにカップがあります

ページを読みこみ直すと、店の表からやり直しになります。

## 2. 席からの景色

お客さんの席は、店のいちばん奥、角のテーブル席です。ここから店全体が見わたせます。

| 場所 | あるもの |
|---|---|
| 左 | 大きな格子窓と坂の町、通りの向かいの木。窓辺にサボテン三つ。窓ぎわに二人がけのテーブルと椅子、色あせた絨毯 |
| 中央の壁 | 壁の時計（あなたの端末の時刻をさします）、おくのさんの空想地図 |
| 中央奥 | カウンター。後ろの棚にカップや豆の瓶、黒板のメニュー。カウンターの上にミル、サイフォン、ミントの鉢 |
| 右 | 古いジュークボックス、天井までの本棚（上にシダ）、大きなモンステラ |
| 天井 | 梁から吊るしたポトス、ペンダントランプ三つ |
| 手前 | 自分のテーブル。開いた本、カップ、小さなランプ |

画面は 320×180 ドットで、1秒に8コマ描いています。

## 3. 時間帯

店の中の時間は、**あなたの端末の時計**とそろっています。時間帯で、光と音楽と住人のすることが変わります。

| 時間帯 | 時刻 | 光 | 「おまかせ」で流れる曲 |
|---|---|---|---|
| 朝 | 5〜10時 | 窓から白っぽい光。床に窓の光が差しこむ | A1 霧の停留所 |
| 昼 | 10〜16時 | いちばん明るい。床に日だまり | A2 午後の地図帳 |
| 夕 | 16〜19時 | 窓から西日。ランプ、手前のランプが灯る | B1 坂の上の灯台 |
| 夜 | 19〜5時 | 外は夜の町の灯り。店の中はランプの明かりだけ | B2 月見坂ノクターン |

### おくのさんの一日

| 時刻 | していること |
|---|---|
| 0〜5時 | うたた寝（ときどき「z」が浮かぶ） |
| 5〜10時 | カップを磨いている |
| 10〜16時 | 本を読んでいる（25秒に一度くらい、ページをめくる） |
| 16〜19時 | 窓の外を見ている（ときどき店の中に目を戻す） |
| 19〜24時 | 空想地図を描いている |

### ゆかしの一日

| 時刻 | 居場所 |
|---|---|
| 0〜5時 | 本棚の三段目で眠る |
| 5〜10時 | 窓ぎわの椅子で丸くなる |
| 10〜16時 | 床の日だまりで眠る（雨や霧で日が差さない日は、窓辺で外を見ている） |
| 16〜19時 | 窓辺に座って外を見ている（ときどき耳をぴくっと動かし、しっぽの先をふる）。店の表の窓からも見える |
| 19〜24時 | 本棚の三段目で眠る |

眠っているときは、ときどき背中が寝息でふくらみます。

### 窓の外

- 雲が三つ、ゆっくり右へ流れています（夜も、暗い雲として流れます）
- 晴れた朝と昼は、ときどき鳥が横切ります
- 晴れた夜は星がまたたき、町の家々に灯りがついています

### 天気

月見坂の天気は三つです。**本当の天気は見ません**（あなたの場所を使いません）。日付と時刻から決まるので、同じ時刻なら誰が来ても同じ天気です。

| 天気 | いつ | 店の中 | 店の表 |
|---|---|---|---|
| 晴れ | ふだん | 3. の表のとおり。昼と朝は窓の光が床に差す | 晴れた空 |
| 霧 | 三日に一日くらいの、朝（5〜10時）だけ | 窓の外が白くかすみ、霧の帯がゆっくり流れる。床に光は差さない | 上ほど白くかすむ |
| 雨 | 3時間ごとに決まり、だいたい6回に1回 | 灰色の空に雨が降り、ガラスをしずくがつたう。昼でもランプが灯る。床に光は差さない | 雨が降り、ぬれた石畳に窓の灯りが映る。ドアの左に傘立て |

- 雨と霧が重なったときは、雨になります
- 雨の日は、音楽を鳴らしているあいだ、**雨音**も小さく聞こえます（音量はジュークボックスの音量といっしょに変わります）
- 「おまかせ」の曲は、雨なら C1 雨やどりのビート、霧なら D2 坂の下の霧になります

## 4. 注文

注文はお客さんが選びません。おくのさんが顔を見て決めます。

| とき | 出てくるもの | おくのさんのことば |
|---|---|---|
| 夜（19〜5時） | 月見ブレンド | 「夜ですから、月見ブレンドにしましょうか。」 |
| 霧の朝 | 霧の朝のミルクコーヒー | 「霧の朝ですから、ミルクコーヒーにしましょう。」 |
| 雨の日 | ゆかしブレンド | 「雨の日は、少し濃いめに淹れておきました。」 |
| はじめての来店 | ゆかしブレンド | 「はじめてでしたら、ゆかしブレンドを。……実はもう、淹れてあるんです。」 |
| 2回目 | ゆかしブレンド | 「今日も、ゆかしブレンドにしましょう。」 |
| 3回目から | ゆかしブレンド | 「いつもので、よろしいですね。」 |

上の段ほど優先されます。天気については 3. の「天気」を見てください。

カップを置いたあと、おくのさんは「どうぞ、ごゆっくり。」と言います。飲みものは、カップの中の色でも見分けられます。

### 甘いもの

時間帯によって、カップといっしょに、カップの右に小皿が置かれます。

| 時刻 | 甘いもの | おくのさんのことば |
|---|---|---|
| 5〜10時 | シナモントースト | 「それと、トーストを。シナモンは、おまけです。」 |
| 13〜16時 | 固めのプリン | 「プリンがちょうど固まったので、よかったら。」 |
| 16〜19時 | レモンケーキ | 「レモンケーキもどうぞ。夏の味がする、冬のお菓子です。」 |
| それ以外 | なし | |

甘いものは、置かれてから8分で半分になり、18分で食べおわって、皿にくずが残ります。おかわりはありません。席に着いた時刻で決まります。

## 5. コーヒーの時間

| 置かれてから | 起きること |
|---|---|
| 0〜6分 | 湯気が三すじ |
| 6〜10分 | 湯気が二すじ |
| 10〜14分 | 湯気が一すじ |
| 14分〜 | 冷めて、湯気が消える |
| 25分 | 飲みおわる |
| 27分 | おくのさんが**黙っておかわりを置いていく**。湯気が戻る（画面を見ていれば、カップを置く音がします） |

**タブのアイコン**は、上から見たカップです。25分かけてコーヒーが少しずつ減り、内側の白い壁が見えてきます。タブが裏にあっても減っていきます。おかわりが来ると、いっぱいに戻ります。

## 6. しばらくいると

- **ゆかしがテーブルに来ます。** 席に着いてから15分たつと最初に来て、そのあとは20分ごとに来ます。1回は1分ほど。こちらを見て、ゆっくりまばたきをし（猫の「好き」の合図）、頭をすりすりして、自分の場所に帰ります。来るところと帰るところは見えません
- 滞在時間は、読みこみ直すと0からになります

## 7. タブに戻ったとき

30秒以上ほかのタブにいて戻ってくると、おくのさんが会釈して「おかえりなさい。」と言います。

## 8. お会計と、帰りかた

カップが置かれると、画面の下の左に**「お会計」**が出ます。押すと、おくのさんが「ありがとうございました。」と言い、**レシート**が出ます。

レシートに書いてあること：

- 日付と時刻、何回目の来店か
- 飲んだもの（おかわりも数えます）と、甘いもの
- ご滞在の時間、ゆかしが来た回数、ひとりごとを聞いた回数
- お代：**またのお越しで**（お金はいただきません）
- 本日のひとこと：最後に聞いたひとりごと。聞いていなければ、おくのさんがひとつ選びます
- ゆかしの足あとのはんこ

レシートの横のボタン：

| ボタン | 起きること |
|---|---|
| レシートを保存 | レシートを画像（PNG）で保存する。ファイル名は `yukashi-年月日.png` |
| もう少しいる | レシートを閉じて、席に戻る。おくのさん「ええ、どうぞ。いくらでも。」 |
| 店を出る | 暗転して、店の表に出る。ドアが閉まって鈴が鳴り、おくのさん「またどうぞ。」（3杯以上飲んでいたら「ゆっくりしていただけて、よかったです。またどうぞ。」）。音楽は止まり、またドアから入れます |

お会計をせずにタブを閉じても、帰ったことになります（いた時間は覚えておきます）。

## 9. さわれるもの

クリック（スマホならタップ）できるものです。さわれるものの上では、カーソルが指の形になります。

| もの | 起きること |
|---|---|
| ドア（店の表） | 入店する |
| おくのさん | ひとりごとを言う。35種類あって、そのうち15は天気や時間帯に合わせたもの（雨の日だけ、夜だけ、など）。同じものは続けて出ない |
| ジュークボックス | 曲目カードを開く（10. を見てください） |
| テーブルに来たゆかし | 「（ゴロゴロ……）」 |
| 本棚の二段目の、リボンのはみ出た帳面 | スケッチ帳が別のタブで開く |
| 画面の下の曲名 | 曲目カードを開く |

ふきだしは、文字数に応じて数秒で消えます。

## 10. 音楽と音

音楽は、カウンターの端の古いジュークボックスから流れている、という設定です。おくのさんが直した古い機械なので、どんな曲もどこか 8bit の音になります。

いちばん大事にしているのは、**作業のじゃまをしないこと**です。

- 和音はやわらかい長調系だけ。メロディは和音の音か、その調の音だけを使い、ぶつかる音は鳴らしません
- メロディは手で作曲したもので、くり返すうちに、休む周（和音とベースだけになる）がはさまります。チップチューンとジャズは4周に1周休み、4周目は1オクターブ下でそっと。ローファイは1周おき。環境音楽にはメロディがありません
- 伴奏（和音の刻み方、ベースの動き、ドラム）は毎回少しずつ変わります

### 曲目（10曲）

| 番号 | 曲名 | 種類 | ひとこと | 速さ（BPM） |
|---|---|---|---|---|
| A1 | 霧の停留所 | チップチューン | 朝の、ゆったりした町の曲 | 84 |
| A2 | 午後の地図帳 | チップチューン | 昼の、少しだけ弾む曲 | 92 |
| A3 | ゆかしのしっぽ | チップチューン | 気ままに、ゆらゆら | 96 |
| A4 | ランプの下で | チップチューン | 夜ふけの、静かな町の曲 | 68 |
| B1 | 坂の上の灯台 | ジャズ | 夕方の、ゆるいスウィング | 100 |
| B2 | 月見坂ノクターン | ジャズ | 夜の、ブラシのバラード | 66 |
| C1 | 雨やどりのビート | ローファイ | 雨の日に、低くくり返す | 78 |
| C2 | 地図の余白 | ローファイ | 何も描いていない、白いところ | 72 |
| D1 | 窓辺の日だまり | 環境音楽 | ゆかしが眠っているあいだ | 56 |
| D2 | 坂の下の霧 | 環境音楽 | 霧の朝の、ぼんやりした空気 | 50 |

### 曲目カード

ジュークボックスか、画面の下の曲名をクリックすると、曲目カードが開きます。

| 選ぶもの | 流れ方 |
|---|---|
| **おまかせ**（はじめはこれ） | 時間帯で曲が変わる（3. の表） |
| **いろいろ** | 4分ほどで、次の曲に移っていく |
| 曲を1つ選ぶ | その曲をずっとくり返す |

- 曲を変えると、今の曲がすっと小さくなって、次の曲が始まります
- カードの下で、**音量**を変えたり、**止める・鳴らす**を切り替えたりできます
- 選曲のしかた、音量、止めたかどうかは、このブラウザに覚えて、次に来たときもそのままです（止めて帰ったら、次も止まったまま入店します）
- いま流れている曲には ♪ がつきます

### そのほか

- 鳴っているあいだ、ジュークボックスに灯りがともり、ときどき音符が浮かびます
- **タブが裏にあっても、音楽は止まりません**（作業のおともなので）
- 効果音は二つ：ドアの鈴、カップを置く音
- ブラウザの決まりで、音はドアをクリックしたあとにしか鳴りません

## 11. 店が覚えていること

店は、**このブラウザの中だけ**に、次のことを覚えています。どこにも送りません。

- 来店した回数
- 前回来た日時
- これまでにいた時間の合計と、飲んだ杯数の合計（今の版では、まだ画面には出しません）
- ジュークボックスの選曲のしかた、音量、止めたかどうか
- スケッチ帳の試聴室でつけた感想

これを使って、あいさつが変わります。

| とき | あいさつ |
|---|---|
| はじめて | 「いらっしゃいませ。」（雨なら「いらっしゃいませ。雨の中、ようこそ。」） |
| 2回目から、雨の日 | 「いらっしゃいませ。降られませんでしたか。」 |
| 2〜4回目 | 「いらっしゃいませ。また来てくださったんですね。」 |
| 5回目から | 「いらっしゃいませ。いつもの席、空いていますよ。」 |
| 前回からひと月以上 | 「いらっしゃいませ。……おや、おひさしぶりですね。」 |

ブラウザのサイトデータを消すと、はじめてのお客さんに戻ります。プライベートブラウズなどで覚えられないときも、はじめてのお客さんとしてもてなします。

## 12. スケッチ帳

店づくりの作業台です。店の中の本棚の帳面からも開けます。

- **角の席から**：店の景色。「いま・朝・昼・夕・夜」で時間帯を、「いまの天気・晴れ・霧・雨」で天気を切り替えられます。いまの時刻、天気、おくのさんのしていること、ゆかしの居場所、滞在時間を表示します
- **店の表**：同じ時間帯と天気の、店の表
- **♪ ジュークボックス**：「おまかせ」で鳴らす・止める
- **試聴室**：10曲を一覧から聴ける。曲ごとに「いい・ふつう・気になる」をつけて、メモを書き、「感想をまとめてコピー」で文章にしてコピーできる（Claude に貼りつけると、それをもとに直します）
- **時間帯の光**：4つの時間帯を並べて見比べる
- **小物**：住人や小物のドット絵を、実寸と拡大で
- **パレット**：店の絵に使う29色
- いちばん下に、いまの版

URL につけると、確認用に時間をいじれます。

| つけるもの | 意味 |
|---|---|
| `?time=18:30` | その時刻から始める |
| `?speed=60` | 60倍速で時間を進める |
| `?stay=900` | もう900秒（15分）いることにする（ゆかしがテーブルに来るところを見られる） |
| `?view=yoru` | 夜の店を開く（`asa` `hiru` `yu` `yoru`） |
| `?weather=ame` | 天気を決める（`hare` `kiri` `ame`）。店（index.html）でも使える |

組み合わせもできます（例：`sketchbook.html?time=15:00&stay=900`）。

## 13. 動く環境と、今の版でできないこと

- 新しめのブラウザ（Chrome、Edge、Firefox、Safari）で動きます。パソコン向けにつくっていて、スマホでも動きます（横向きのほうが見やすい）
- 軽さ：1コマ3ミリ秒ほど。タブが裏にあるあいだは、絵を描くのを止めます（音楽とタブのアイコンは続きます）
- 入店の演出は飛ばせません

## 開発する人へ

### つくり

ビルド不要の素の HTML / CSS / JavaScript だけで動きます。本番ではライブラリを使っていません。

| 場所 | 中身 |
|---|---|
| `index.html` / `src/main.js` | 店。入店から、過ごすあいだのこと |
| `sketchbook.html` / `src/sketchbook.js` | スケッチ帳 |
| `src/scene.js` | 店の中の景色、住人、時間帯ごとの光、できごと |
| `src/facade.js` | 店の表 |
| `src/sprites.js` | ドット絵。1文字＝1ドットの文字列で描く |
| `src/palette.js` | 店の色（29色） |
| `src/pixel.js` | ドット絵を描く道具と、光の計算 |
| `src/music.js` | ジュークボックス：曲目、楽器、演奏、効果音。メロディは楽譜の文字列で書く |
| `src/jukebox-panel.js` | ジュークボックスの曲目カード |
| `src/lines.js` | おくのさんのもてなしのことば、注文の決め方 |
| `src/hitorigoto.js` / `data/hitorigoto.txt` | おくのさんのひとりごと（1行に1つ） |
| `src/guest.js` | 店が覚えているお客さんのこと（localStorage） |
| `src/favicon.js` | タブのアイコン |
| `src/receipt.js` | お会計のレシート |
| `src/weather.js` | 月見坂の天気 |
| `src/version.js` | 版 |
| `docs/` | 設定資料 |
| `tools/` | 確認用の道具 |

### 手元で動かす

```
npm install                  # はじめの一回（確認用の Playwright が入る）
npm run serve                # http://127.0.0.1:8080/
npm run shot -- "sketchbook.html?time=18:30" shots/yu.png 1000 --el=#scene   # 画面を撮る
npm run perf                 # 1コマを描く重さを測る
npm run listen -- all 30     # 全曲を wav に書き出して、音量・音割れ・無音を確かめる（曲の id を書けば1曲だけ）
```

### バージョン

区切りごとに番号をつけて、git のタグと GitHub のリリースに残しています。番号は `package.json`、`src/version.js`、`CHANGELOG.md`、この説明書のいちばん上の四か所をそろえます。設定資料もソースと同じ場所にあるので、どの版でも「そのときの店」と「そのときの設定」がそろって見られます。前の版に戻る方法は [docs/versions.md](docs/versions.md) にあります。
