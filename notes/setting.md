# 喫茶ゆかし 設定ノート

二人で育てる、店の決まりごとと想像のメモ。決まっていないことは「？」のまま置いておく。

## この店について

- ピクセルアートの喫茶店に「入店」して、そこで過ごすサイト
- 開きっぱなしにして、人はその間に別の作業をしている
- 邪魔はしない。でも、ふと目をやると何かが起きていて、ちょっといい気分になる
- ゲームっぽさはない。ただ落ち着いて、居心地がよくて、空間に浸っていられる
- 動画との違い：店があなたのことを覚えていて、あなたの時間と一緒に流れていること

## 店づくりの決まり

- 変化は「見たときに気づく」くらい。タブを点滅させたりして呼びつけない
- 迷ったら、静かなほう・ゆっくりなほうを選ぶ
- 絵はパレット（src/palette.js）の色だけで描く
- 光はなめらかなグラデーションにせず、段階と網点で表す
- ライブラリなし、ビルドなし。素の HTML / CSS / JavaScript で、10年後も動くように

## 店の場所と見た目

- レトロで落ち着いた色合い。重厚で、空気を感じるピクセルアート
- 時計は入店した時刻と連動。時間帯で外の光と店の雰囲気が変わる
- コーヒーの湯気。静かなチップチューン
- お客さんの席は？（カウンター／窓際のテーブル）

## おくのさん（オーナー）

- 白髪のおじさん。落ち着いていて、空想家
- 好きなもの：読書、コーヒー、猫
- 白シャツに、黒や茶色のベスト
- しゃべり方：ていねい、ゆっくり。「〜なんです」「〜でしょうね」
- ひとりごとは data/hitorigoto.txt（1行ずつ書き足せる）
- 名前の漢字は？　年齢は？

## ゆかし（看板猫）

- おくのさんの飼い猫。三毛猫
- しばらくいると、そっと近づいてきてすり寄ってくる
- 好きな場所は？　苦手なものは？

## メニュー

- 「いつもの」は？
- ほかに何がある？

## 体験の流れ

1. ドアをクリックして入店。「いらっしゃいませ」。BGMが流れはじめる
2. 一人称視点で席まで案内されて、座る
3. おくのさんがオーダーを取りに来て、いつの間にか注文が決まっている
4. そこからは同じ景色のまま、アニメーションがゆっくり続く

## アイデアの引き出し

やるかどうかは未定。思いついたら足していく。

- タブのアイコンのコーヒーが少しずつ減っていく
- タブに戻ると、おくのさんが「おかえりなさい」と会釈
- 何度か来ると「いつもの」が出てくる
- おくのさんをクリックすると、空想家らしいひとりごと
- 暦（二十四節気）で店の小物が入れ替わる
- おくのさんの本のページが進み、読み終わると次の一冊へ
- 深夜は「夜更かし営業」。ランプひとつと、おくのさんのうたた寝
- 一定時間ごとに、黙っておかわりを注いでくれる（数字のないタイマー）
- 帰るときに「お会計」。滞在時間・杯数・ゆかしが来た回数が書かれたレシート
- ゆかしは窓辺、本棚の上、隣の席と気ままに移る。長くいる日だけ膝で寝る
- （先の話）同じ時間にいるほかのお客さんの気配、らくがき帳
